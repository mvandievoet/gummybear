# Mechanical CAD (`Casio W-218H` Mod)

3D-printable STLs / STEP / parametric `build123d` models for Google Makerspace fabrication (Phase 4):
1. **Snap-in Internal Cradle:** Aligns the `nice!view` Sharp Memory LCD behind Casio's clear front window, holds the `GM10 Nano V3` patch antenna skyward under the top bezel, and positions `3×` right-angle tactile switches (`0.2 mm` gap) directly behind Casio's sliding exterior pusher pins.
2. **`+3.8 mm` Custom Backplate:** Reuses Casio's 4 original corner screws with a `1.5 mm` O-ring sweat seal and plugged USB-C port (V1) / flush 2-pin magnetic pogo target (V2).
